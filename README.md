# DG-LAB-Client-Web

DG-LAB-Client 的应用官网与静态资源分发站点。

## 定位

本仓库承载网站本身，负责两件事：

1. **应用官网** — 下载入口、版本发布说明、使用文档与插件市场的前端页面。
2. **静态资源分发** — 图标、封面、截图等二进制资源，通过稳定路径对外提供。

站点的构建产物与页面代码会在后续阶段引入；当前仓库只包含许可协议与这份说明。

## 资源路径

插件封面等静态资源统一托管在本站，供客户端与市场页面引用。
